Сторонние компоненты Birch
==========================

Birch распространяется по Mozilla Public License 2.0 (файл LICENSE).

В готовые пакеты Birch для macOS, Windows и AppImage входят библиотеки
других проектов. Они распространяются по своим лицензиям, тексты которых
лежат в папке licenses.


Qt 6
----
Авторы: The Qt Company Ltd. и другие участники проекта Qt.
Лицензия: GNU Lesser General Public License версии 3 — licenses/LGPL-3.0.txt.
  LGPL дополняет GNU General Public License версии 3 — licenses/GPL-3.0.txt.
Исходный код: https://download.qt.io/official_releases/qt/
Qt подключается динамически — отдельными библиотеками рядом с программой,
поэтому его можно заменить своей сборкой Qt той же версии.


Qt в пакете для Windows 8.1
---------------------------
В пакете Birch-…-windows8-x64 библиотеки Qt Core, Gui, Widgets, Network и
плагины platforms, styles и imageformats заменены версиями той же версии Qt
с исправлениями проекта qt6windows7, которые позволяют Qt 6 работать на
Windows 7, 8 и 8.1. Это изменённый Qt, он распространяется по той же
лицензии GNU LGPL версии 3.
Исправления и описание изменений: https://github.com/crystalidea/qt6windows7
Исходный код Qt: https://download.qt.io/official_releases/qt/
Остальные модули Qt (Svg, SvgWidgets и их плагины) — из официальной сборки.

В тот же пакет входит универсальная среда выполнения C (UCRT, файлы
ucrtbase.dll и api-ms-win-*.dll) из Windows SDK — Microsoft разрешает
распространять её вместе с программами.


Graphviz
--------
Авторы: AT&T Labs Research и другие участники проекта Graphviz.
Лицензия: Eclipse Public License 2.0 — licenses/EPL-2.0.txt.
Исходный код: https://gitlab.com/graphviz/graphviz
Используются библиотеки gvc, cgraph, cdt, pathplan и xdot и плагины
dot_layout и core; плагины могут быть встроены в программу.


Библиотеки в пакетах для macOS и AppImage
-----------------------------------------
Вместе с Qt и Graphviz в эти пакеты входят библиотеки, от которых они зависят:
FreeType, HarfBuzz, ICU, GLib, PCRE2, libpng, zstd, D-Bus, библиотеки X11 и
другие. Их точный список с версиями и лицензиями собирается автоматически при
упаковке из пакетов, откуда они взяты, — вместе с текстами лицензий:
  macOS:    Birch.app/Contents/Resources/licenses/LIBRARIES.txt
            (пакеты Homebrew, тексты — в licenses/homebrew)
  AppImage: usr/share/doc/birch/licenses/LIBRARIES.txt
            (пакеты Ubuntu, тексты — в licenses/ubuntu)
В AppImage библиотеки ICU взяты из сборки Qt: лицензия — licenses/ICU.txt.
Birch эти библиотеки не изменяет.


Expat
-----
Используется Graphviz в пакете для Windows (libexpat.dll).
Авторы: Thai Open Source Software Center Ltd, Clark Cooper и разработчики Expat.
Лицензия: MIT — licenses/Expat.txt.
Исходный код: https://github.com/libexpat/libexpat


zlib
----
Используется Graphviz в пакете для Windows (zlib1.dll).
Авторы: Jean-loup Gailly и Mark Adler.
Лицензия: zlib — licenses/zlib.txt.
Исходный код: https://zlib.net


Среда выполнения Microsoft Visual C++
-------------------------------------
В пакетах для Windows лежат библиотеки среды выполнения Microsoft Visual C++
(msvcp140*.dll, vcruntime140*.dll, concrt140.dll), а в пакете для Windows 8.1
ещё и универсальная среда выполнения C (ucrtbase.dll, api-ms-win-*.dll).
Microsoft разрешает распространять их вместе с программами, собранными
Visual Studio («Distributable Code» в лицензии Visual Studio и Windows SDK).
