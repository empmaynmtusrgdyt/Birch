# Birch

Приложение для macOS, которое строит блок-схемы по текстовому описанию. Без ИИ и без интернета: текст разбирает собственный парсер, раскладку и стрелки делает [Graphviz](https://graphviz.org), интерфейс написан на Qt 6.

![Birch](docs/screenshot-light.png)

```text
(Старт) -> [Ввод_данных] -> {Данные корректны?};
{Данные корректны?} -> [Сохранить] "Да" -> (Конец);
{Данные корректны?} -> [Показать_ошибку] "Нет" -> [Ввод_данных];
```

## Возможности

- Редактор слева, схема справа. Схема перерисовывается автоматически через 300 мс после паузы в наборе; рендер идёт в фоновом потоке, поэтому набор не подвисает.
- Ошибки подчёркиваются прямо в тексте: строка, позиция и понятное сообщение. Недописанная строка не ломает остальную схему.
- Векторный холст: масштаб через ⌘ + колесо или щипок на трекпаде, прокрутка перетаскиванием, двойной щелчок вписывает схему в окно.
- **Скачать PNG** (⌘E) и **Копировать в буфер** (⌘⇧C): картинку можно сразу вставить в Telegram, Slack, Pages, Word или Discord. Есть экспорт в SVG и прозрачный фон.
- **Чёрно-белый режим** (кнопка «Ч/Б», ⌘⇧B): чёрные линии и текст на белом, для печати и документов.
- Светлая и тёмная темы следуют системной; тему можно выбрать и вручную. Тему картинки можно задать отдельно, например всегда светлую для документов.
- Файлы `.birch` открываются двойным щелчком в Finder. Несохранённый текст восстанавливается при следующем запуске.

## Установка

Скачайте `.dmg` со страницы [Releases](https://github.com/empmaynmtusrgdyt/Birch/releases), откройте его и перетащите **Birch** в «Программы».

Приложение подписано ad-hoc, а не сертификатом Apple Developer ID, поэтому при первом запуске macOS его заблокирует. Чтобы открыть его один раз, щёлкните по Birch в «Программах» правой кнопкой и выберите **«Открыть»**. Или выполните в Терминале:

```bash
xattr -dr com.apple.quarantine /Applications/Birch.app
```

Готовые сборки работают на **Apple Silicon** с той версией macOS, под которую собраны библиотеки Homebrew на сборочной машине (сейчас **macOS 26+**). Для других систем соберите приложение из исходников — см. ниже.

## Синтаксис

| Запись | Значение |
|---|---|
| `[Текст]` | шаг (скруглённый прямоугольник) |
| `{Условие?}` | решение (ромб) |
| `(Старт)` | начало или конец |
| `[A] -> [B]` | стрелка; можно цепочкой: `[A] -> [B] -> [C]` |
| `[A] -> [B] "Да"` | подпись стрелки, ведущей в `[B]` |
| `;` или перевод строки | конец инструкции; строка, начинающаяся с `->`, продолжает предыдущую |
| `// …` или `# …` | комментарий |
| `_` | пробел в тексте узла; `\_` — само подчёркивание |
| `\n` | перенос строки внутри текста |
| `\]`, `\"`, `\\` | символ как есть |

Одинаковый текст обозначает один и тот же узел. Если узел хоть раз записан как `{…}` или `(…)`, он остаётся этой фигурой, даже если дальше написан как `[…]`. Стрелка `→` и кавычки `«»` и `“”` (их подставляет автозамена macOS) тоже поддерживаются.

| Клавиши | Действие |

| ⌘↩ или ⌘R | перерисовать схему |

## Сборка из исходников

Нужны Xcode Command Line Tools, CMake ≥ 3.21, Qt ≥ 6.5 (модули Base и Svg) и Graphviz ≥ 9:

```bash
xcode-select --install          # компилятор, если ещё не установлен
brew install cmake qt graphviz
```

Сборка, тесты и запуск:

```bash
cmake --preset macos
cmake --build --preset macos
ctest --preset macos
open build/macos/Birch.app
```

При настройке CMake печатает строку вида `Birch 0.1.0: Qt 6.9.3, Graphviz 16.1.0, builtin plugins: TRUE`. Значение `builtin plugins: TRUE` означает, что плагины Graphviz встроены в приложение и ему не нужен установленный Graphviz во время работы.

Тесты (парсер и рендерер, около 50 проверок) собираются по умолчанию; отключаются флагом `-DBIRCH_BUILD_TESTS=OFF`. Файл можно открыть из Терминала: `open -a Birch схема.birch`.

## Сборка .dmg

```bash
cd build/macos && cpack          # -> Birch-<версия>-macos-<arch>.dmg
```

Что происходит при упаковке:

1. `macdeployqt` копирует Qt и все библиотеки, включая Graphviz, внутрь `Birch.app`.
2. `packaging/macos/prune-bundle.cmake` удаляет лишнее (QtQuick, QML, PDF-плагин), докопирует то, что `macdeployqt` пропустил, убирает пути машины сборки и **проверяет, что бандл самодостаточен**: если какой-то библиотеки не хватает, упаковка завершится ошибкой, а не выдаст сломанный `.app`.
3. Бандл подписывается ad-hoc. Размер `.dmg` около 30 МБ.

**Минимальная версия macOS.** Пакет работает на тех версиях macOS, под которые собраны библиотеки. Homebrew на свежей системе собирает Graphviz под самую новую macOS, поэтому `.dmg` с такой машины на старых системах не запустится. Для широкой совместимости соберите Qt и Graphviz с нужной минимальной версией и передайте `-DCMAKE_OSX_DEPLOYMENT_TARGET=12.0`.

**Распространение.** Ad-hoc подписи достаточно для своей машины. Чтобы Gatekeeper не блокировал приложение у других пользователей, подпишите его сертификатом Developer ID (замените `-` в `cmake/Packaging.cmake` на имя сертификата) и нотаризуйте через `xcrun notarytool`.

## Структура проекта

```text
Birch/
├── CMakeLists.txt            сборка: цели birch_core и Birch, бандл macOS
├── CMakePresets.json         пресет macos (configure, build, test)
├── cmake/
│   ├── FindGraphviz.cmake    поиск Graphviz: pkg-config, затем вручную
│   └── Packaging.cmake       установка, деплой Qt, .dmg
├── src/
│   ├── main.cpp
│   ├── core/                 логика без виджетов, покрыта тестами
│   │   ├── Diagram.h         модель: узлы, связи, фигуры
│   │   ├── Parser.*          DSL → Diagram, ошибки с позициями
│   │   ├── Renderer.*        Diagram → Graphviz (cgraph + dot) → SVG → QImage/PNG
│   │   └── Theme.*           цветные (светлая, тёмная) и чёрно-белые палитры
│   ├── app/
│   │   └── RenderController.*  фоновый рендер, «побеждает последний запрос»
│   └── ui/
│       ├── MainWindow.*      окно, меню, экспорт, файлы, темы
│       ├── CodeEditor.*      редактор: номера строк, подчёркивание ошибок
│       ├── SyntaxHighlighter.*
│       └── PreviewView.*     интерактивный холст (вектор, зум, прокрутка)
├── resources/                иконки интерфейса, пример схемы
├── packaging/
│   ├── generate-icons.sh     app.svg → app.icns
│   └── macos/                Info.plist, иконка, проверка бандла
├── tests/                    тесты парсера и рендерера (Qt Test)
└── docs/                     скриншоты
```

### Как устроен рендеринг

1. `Parser` превращает текст в `Diagram` и список ошибок. Инструкция применяется целиком или не применяется вовсе, поэтому при наборе схема не «мигает».
2. `Renderer` строит граф через C++ API Graphviz (`cgraph`), задаёт стили атрибутами из `Theme` (скругления, цвета, шрифт, стрелки), раскладывает граф движком `dot` и получает SVG через `gvRenderData`.
3. Ширину текста для Graphviz измеряет Qt, тем же шрифтом, которым потом рисуется SVG: в Graphviz зарегистрирован собственный плагин `textlayout`. Без него Graphviz оценивает ширину по встроенной таблице, и кириллица вылезает за рамки узлов.
4. Превью показывает SVG как вектор (`QGraphicsSvgItem`), а экспорт растеризует его в PNG с масштабом 2× для Retina.

## Решение проблем

| Симптом | Что делать |
|---|---|
| `Could NOT find Graphviz` | `brew install graphviz` или укажите путь: `-DGRAPHVIZ_ROOT=/путь/к/graphviz`. |
| `Could NOT find Qt6Svg` / `SvgWidgets` | `brew install qt` (модуль SVG входит в него) и проверьте, что `CMAKE_PREFIX_PATH` указывает на Homebrew. |
| `Birch поддерживает только macOS` | Проект собирается только на macOS. |
| После смены параметров CMake ничего не меняется | Значения опций кэшируются: передайте их явно (`-DBIRCH_BUILD_TESTS=ON`) или удалите папку `build/macos`. |
| «Birch повреждено» или «не удаётся проверить разработчика» | Пакет подписан ad-hoc. Откройте через контекстное меню → «Открыть» или выполните `xattr -dr com.apple.quarantine /Applications/Birch.app`. |

Иконка приложения (`packaging/macos/app.icns`) генерируется из `resources/icons/app.svg` скриптом `packaging/generate-icons.sh`.
